🚀 Advanced User Management System

An advanced, scalable User Management System built with React, TypeScript, and Tailwind CSS, backed by Node.js, Express, and MongoDB. It supports JWT authentication, role-based access control (RBAC), real-time activity monitoring, and audit logging.

✨ Features

🔐 Authentication (JWT, OAuth-ready)

👤 Role-based Access Control (Admin, Manager, User, etc.)

📋 User Profiles with Editable Info

🔍 Search & Filter Users

📈 Activity Logs and Audit Trails

🌐 RESTful API (OpenAPI/Swagger compliant)

💬 Real-time notifications (WebSocket-based)

🌙 Dark Mode and Theme Support

🧪 Unit & Integration Tests with Jest and React Testing Library

🚀 Production-ready (CI/CD, Docker, ENV config)
